
| 25 | ✅ | Inline vector access | Ceiling first: unchecked array access was worth 1.4–2.1x on the vector-heavy programs. The planned expansion, the checks inline like `car`'s, was slower than the primitive in isolation and caught little of that, since comparing a `bigint` index costs more than converting it (R72). What caught nearly all of it: the expansion calls a runtime helper, `R.vectorRef`/`R.vectorSet`, which converts the index once, handles an array and an exact index in range, and passes everything else -- every error included -- to the primitive; `vector-length` is inline. Suite, compiled: `flonum` 1.26x (`simplex` 1.82x), `vector` 1.18x (`array1` 1.38x), `list` 1.07x (`earley` 1.34x), nothing else moved; interpreter unchanged. Against the interpreter, `vector` 35x and `flonum` 131x. The same helper would suit `string-ref` and `bytevector-u8-ref`, unmeasured. | R72 |
