
| 31 | ✅ | A differential fuzzer across the two tiers | A generator in Scheme (`tests/fuzz/program_generator.scm`) builds a terminating, deterministic program from a seed -- loops, closures, assignments, escapes, a continuation captured at a random site and re-entered twice, errors raised and caught or not, `dynamic-wind`, multiple values, higher-order calls through the library, deep recursion alternating between tiers -- and chooses which procedures to compile, captures allowed. Each runs interpreted and compiled, answers compared; 120 fixed seeds in `npm test` (3.6 s), `run_fuzz.js` for more. Five reintroduced bugs (a nested run passing no frames on, the capturing run's frames dropped, collected frames stacked the wrong way, assigned locals never boxed, a spill saving only its own block's reads) each found within the first 27 programs. Its first 5,000 programs found six wrong answers, one cause: compiled code evaluated a call's variable operands, and the procedure, after the operands to their right (R81). Fixed in `emit-operands!`: speed unchanged, code 0.9% (libraries) and 3.8% (compiler) larger. Does not reach interop or I/O, strings, records, rest parameters or chars; extend the generator when a bug escapes it. | R26, R49, R53, R81 |
